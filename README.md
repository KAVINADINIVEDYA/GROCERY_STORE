🛒 Python Grocery WebApp

The Python Grocery WebApp is a full-stack web application designed to streamline grocery store management. It provides a practical example of how frontend, backend, and database technologies work together to create a functional system.

This project is ideal for learners who want hands-on experience with web development using Python and Flask.

📌 Features

✅ Add, edit, and delete products

✅ Manage customer orders

✅ Maintain stock levels with UOM (Units of Measurement)

✅ View detailed order summaries

✅ Responsive UI built with Bootstrap

✅ API support for products, UOMs, and orders

🏗️ Tech Stack

Frontend: HTML, CSS, JavaScript, Bootstrap

Backend: Python (Flask)

Database: MySQL

📝 Problem Statement

Manual Record-Keeping Issues
Many stores still track products, orders, and customer details manually, which can lead to errors, misplaced information, and inefficiency. This system digitizes all records, making data management faster and more accurate.

Order and Inventory Management
Tracking stock levels, UOM, and customer orders manually is time-consuming and prone to mistakes. This app simplifies the process with CRUD operations and auto-calculated totals.

Improved Efficiency and Decision Making
Store owners gain quick access to product details, inventory levels, and order summaries, enabling smarter decisions and faster service.
